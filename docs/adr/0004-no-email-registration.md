# ADR-0004：注册不设邮箱、不做找回密码

- 状态：已接受
- 日期：2026-08-04

## 背景
注册流程需要权衡字段与功能范围。

## 决策
- 注册字段：用户名 + 密码 + 昵称（用户名全局唯一，密码 bcrypt 哈希）。
- 不做邮箱验证、不做找回密码。

## 理由
- 邮箱验证与找回密码依赖 SMTP 服务，引入外部依赖与配置成本，demo 阶段收益低。
- 用户自用场景密码可自行管理；忘记密码时重新注册成本可接受。

## 后果
- 忘记密码无法自助恢复，需要重新注册。
- 未来若需要邮箱找回，需要 schema 迁移（users 表加 email 列）并接入邮件服务。
