# ADR-0003：数据归属采用"服务器为准"+ 一次性导入

- 状态：已接受
- 日期：2026-08-04

## 背景
旧版数据在 localStorage，无多端同步。引入账号后需要确定数据归属模型。

## 决策
- 登录后任务/目标/笔记全部以服务器数据为唯一事实来源（每行数据归属 user_id）。
- 首次登录后提供一次性"导入本地数据"，把旧版导出的 JSON 迁入账号（导入时重新生成 id、做字段校验与补全）。
- 存储使用 SQLite；Node ≥ 24 优先使用内置 `node:sqlite`，避免原生依赖。

## 理由
- 多端同步是登录的核心价值；服务器为准模型最简单，避免双向合并冲突。
- 不做游客模式 + 合并（复杂度高，demo 阶段不值）。

## 后果
- 未登录不可用全部功能。
- 多设备并发编辑同一数据存在最后写入胜出（last-write-wins）问题，当前单人低并发场景可接受。
