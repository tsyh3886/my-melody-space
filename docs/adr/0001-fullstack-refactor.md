# ADR-0001：从单文件纯前端重构为前后端全栈

- 状态：已接受
- 日期：2026-08-04

## 背景
原 MVP 是 580KB 的单文件纯前端应用，数据存 localStorage。用户目标从"自用 demo"升级为"求职展示 + 自用"，需要更完整的全栈故事和多端数据同步能力。

## 决策
- 后端：Node.js + Express + SQLite（登录、JWT 鉴权、CRUD API）。
- 前端：原生 ES Modules 多文件工程，不引入框架与构建工具。
- 仓库结构：单仓库 `my-melody-space/`，`server/` 放后端，`public/` 放前端静态资源，生产环境由 Express 托管 `public/`。
- 原单文件保留在 `C:\Users\颜家如\WorkBuddy\2026-08-01-17-15-26\` 作归档，不再演进。

## 理由
- 同源部署消除 CORS 配置成本。
- "零依赖原生 JS + 自建后端" 是差异化卖点，面试可讲的层次多。
- SQLite 零运维，本地可跑，后续可平滑迁移到 PostgreSQL。

## 后果
- 失去双击即开（file://）能力，需要 Node 运行时。
- 真正离线可用成为归档单文件的专属特性；新版离线只缓存 App Shell。
